WSL2 + Ubuntu

初心者向けセットアップガイド

Windows上でLinux環境を構築

はじめに：WSL2とUbuntuとは？

このアプリケーションは、Windowsのパソコンの中で「Linux（リナックス）」という別のシステムを動かすための設定手順を、ステップバイステップでナビゲートするガイドです。左側（モバイルの場合は上部）のメニューから順番に進めていくことで、安全かつ確実に環境を構築できます。

🪟

WSL2 とは？

Windows Subsystem for Linux 2の略称です。Windowsの中でLinuxをネイティブに近い速度で動かすための「土台」となる強力な機能です。

🐧

Ubuntu とは？

世界で最もよく使われている初心者にも優しいLinuxの種類（OS）です。今回はMicrosoft Storeで提供されている標準的な「Ubuntu」をインストールします。（通常は最新の安定版がインストールされます）

事前準備：仮想化機能の確認

インストールを進める前に、お使いのパソコンで「仮想化」という機能がオンになっているか確認する必要があります。この機能が無効だとWSL2は動作しません。

🔍 確認手順
  1. キーボードの Ctrl + Shift + Esc キーを同時に押して、「タスク マネージャー」 を開きます。
  2. 左側のメニューから 「パフォーマンス」（波線のアイコン）をクリックします。
  3. 「CPU」 を選択し、画面右下の方にある 「仮想化」 の項目を確認します。
✅

「有効」になっている場合

準備OKです！そのまま次のステップへ進んでインストールを開始できます。

⚠️

「無効」になっている場合

パソコンの「BIOS設定」から仮想化（VT-x や SVM）をオンにする必要があります。設定方法はパソコンのメーカーごとに異なるため、ご自身のPCメーカーのサポートページを検索してご確認ください。

インストール手順

Windowsの「PowerShell」でWSL機能を有効化した後、Microsoft StoreからUbuntuをインストールします。以下の手順に沿って進めてください。

⚙️ ステップ 1：PowerShellを「管理者」として開く

※通常の開き方ではなく、必ず「管理者」として開く必要があります。

  1. Windowsのスタートボタン、または検索窓（虫眼鏡マーク）をクリックします。
  2. キーボードで powershell と入力します。
  3. 検索結果の「Windows PowerShell」の右側にある 「管理者として実行」 をクリックします。
  4. 確認画面が出たら 「はい」 をクリックします。
💻 ステップ 2：WSL有効化コマンドの実行

青い（または黒い）画面が開いたら、以下のコマンドをコピーして、PowerShellの画面上で「右クリック」して貼り付け、Enterキーを押します。

管理者: Windows PowerShell
PS C:\Windows\system32> wsl --install --no-distribution

画面に文字が流れ、「要求された操作は正常に終了しました。」などのメッセージが出たら完了です。

🔄

ステップ 3：パソコンの再起動

機能の有効化を完全に反映させるため、ここで必ずパソコンを一度再起動してください。再起動後、次のステップに進みます。

🛍️ ステップ 4：Microsoft StoreでUbuntuを入手

再起動が完了したら、Linuxの本体である「Ubuntu」をインストールします。

  1. Windowsのスタートメニューから 「Microsoft Store」 アプリを開きます。
  2. 上部の検索窓で Ubuntu と検索します。
  3. 検索結果から「Ubuntu」を選び、「入手」 （または「インストール」）ボタンをクリックします。
  4. ダウンロードが完了すると「開く」ボタンが表示されます。（※ここで急いで開くとエラーになることがあるため、次のステップの注意を読んでから開いてください）

Ubuntuの初期設定 ※最大の難所です！

Storeで「開く」ボタンを押すか、スタートメニューから「Ubuntu」を開くと、黒い画面が立ち上がります。数分待つと、初期設定の入力画面になります。

⚠️

「Error: 0x8000000d」と表示された場合（焦らないで！）

Microsoft StoreからUbuntuをインストールした場合や、処理が終わる前に急いで開こうとした際、以下のようなエラーが出ることがあります。

Installing, this may take a few minutes...
WslRegisterDistribution failed with error: 0x8000000d
Error: 0x8000000d ????????????????

Press any key to continue...
☕

解決法：そのまま数分間待つだけです

これは「裏側での準備がまだ終わっていない」というエラーです。Enterキーを押してこの黒い画面を閉じ、1〜3分ほど待機してから、再度スタートメニューから「Ubuntu」を開き直してください。

1. ユーザー名の決定

画面に Enter new UNIX username: と表示されたら、好きなユーザー名を入力して Enter キーを押します。

※注意：半角の小文字の英語と数字のみが使えます。大文字やスペースは使えません。（例: taro, pcuser1 など）

⚠️ 2. パスワードの決定（※要注意ポイント）

画面に New password: と表示されたら、パスワードを入力して Enter キーを押します。

【超重要】文字が見えません！

セキュリティの都合上、キーボードを叩いても画面には「*」などの文字が一切表示されず、カーソルも動きません。 しかし、パソコンはしっかりと入力を受け付けています。文字が出てこなくても慌てずにパスワードを打ち込み、Enterキーを押してください。

Enter new UNIX username: taro
New password: <-- タイピングしても画面は変化しません

3. パスワードの再確認

Retype new password: と表示されたら、先ほどと同じパスワードをもう一度見えない状態で入力し、 Enter キーを押します。

緑色の文字で ユーザー名@パソコン名:~$ と表示されたら、初期設定は無事に成功です！🎉

最初のおまじない（システムの最新化）

インストールしたばかりのUbuntuの中身を、最新の安全な状態にするためのアップデート（更新）作業を行います。この作業はLinuxを使う上での基本となります。

1 パッケージ一覧の更新

以下のコマンドをコピーし、Ubuntuの画面上で右クリックして貼り付け、Enter を押します。

Ubuntu
user@pc:~$ sudo apt update

※途中で [sudo] password for... と聞かれたら、前のステップで決めたパスワードを見えない状態で入力しEnterを押します。

2 システムのアップグレード

処理が終わったら、次に以下のコマンドをコピーして貼り付け、Enter を押します。

Ubuntu
user@pc:~$ sudo apt upgrade -y

文字がたくさん流れます。再び一番下の行が ~$ で終わる状態になれば、すべてのセットアップは完了です！

🎉

セットアップ完了！お疲れ様でした。

これでWindows上でLinux環境が自由に使えるようになりました。
